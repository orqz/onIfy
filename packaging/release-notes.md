A smooth, lightweight Spotify client. Needs Spotify Premium.

**Install**

- **Windows**: run `onIfy-setup-x86_64.exe`. No admin rights needed.
- **macOS** (Apple Silicon, macOS 15 or newer): open `onIfy-macos-arm64.dmg` and drag onIfy into Applications. The first time, right-click onIfy → Open (it isn't signed with an Apple developer ID).
- **Linux**: download `onIfy-x86_64.flatpak` and install it with `flatpak install --user onIfy-x86_64.flatpak` (works on any distro with Flatpak and Flathub set up). Arch users can also build the package in `packaging/arch`.

Log in with your Spotify account in the browser window that opens. Discord status and Last.fm scrobbling work through Spotify's own connections, the same as the official app.
